# Sistema de diseño

## Dirección visual

La propuesta visual combina tradición institucional con una composición actual, aireada y legible. Debe transmitir experiencia, seriedad, confianza y cercanía, sin recursos gráficos jurídicos genéricos ni exceso ornamental.

## Tokens iniciales

| Token | Valor | Uso previsto |
| --- | --- | --- |
| Bordó institucional | `#701F32` | Acciones y acentos de marca |
| Bordó oscuro | `#4D1424` | Estados de alto contraste |
| Crema | `#F7F3EC` | Fondos cálidos |
| Blanco | `#FFFFFF` | Superficies y texto sobre color |
| Texto | `#252525` | Texto principal |
| Gris | `#6B6B6B` | Texto secundario |
| Dorado discreto | `#B49A67` | Acentos limitados |

## Tipografía

Usar serif elegante en títulos y sans-serif moderna en cuerpo. La elección final debe priorizar legibilidad, rendimiento, licencias adecuadas y soporte de español. Evitar cargar varias familias o pesos sin necesidad.

## Imágenes

Priorizar fotografías reales autorizadas del estudio. Hasta que estén disponibles, usar módulos vacíos o placeholders identificados como tales; nunca presentar una imagen ficticia como foto real del estudio o sus profesionales.

## Interacción y responsive

Diseño mobile-first, navegación operable por teclado, foco visible y objetivos táctiles cómodos. El menú móvil debe conservar semántica y estado anunciado. Respetar `prefers-reduced-motion` y evitar animación decorativa.
